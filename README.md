# JumpUpGame
<h1>Juego Creado con el Framework UIKIt para jugar en IPad 😁 👍 🚀 </h1>
<h3>Hola a todos! 👋 Recientemente he estado trabajando en un proyecto personal para profundizar en el desarrollo nativo con Swift y UIKit. Se trata de un juego de plataformas infinito que, aunque parece simple, me ha permitido aplicar conceptos fundamentales de ingeniería de software y desarrollo móvil.</h3>h3

Durante este proceso, logré implementar:
<dt>✅ Física y Motores de Ciclo: Implementación de un CADisplayLink para gestionar el gameLoop, permitiendo una tasa de refresco sincronizada con la pantalla para un movimiento suave del personaje.</dt>
<dt>✅ Lógica de Reciclaje de Vistas: Diseñé un sistema de "Object Pooling" manual para las plataformas y nubes. En lugar de crear objetos infinitos, las vistas se reciclan al salir de pantalla, optimizando el uso de memoria y CPU</dt>
<dt> ✅ Experiencia de Usuario (UX) y Audio: Integré AVFoundation para feedback auditivo y CoreAnimation / UIView.animate para efectos de "Squash and Stretch", logrando una interfaz orgánica y responsiva.</dt>
<dt>✅ Persistencia de Datos: Uso de UserDefaults para gestionar y almacenar el récord local (High Score) de forma persistente.</dt>
<dt>✅ Adaptabilidad: El juego es totalmente responsivo, ajustando su layout dinámicamente tanto para iPhone como para iPad mediante cálculos de frames proporcionales.</dt>
